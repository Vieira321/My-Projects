# Twelve-Factor App Methodology

## Definition
A set of twelve principles for building SaaS applications that are portable
across environments and easy to scale.

## Key Points
- Strict separation of config from code (config in the environment).
- Stateless, share-nothing processes.
- Backing services as attached, swappable resources.
- Separated build, release, and run stages.
